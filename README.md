# 一个学习git的仓库

## 1. 啥是`git`？

**就是用来拉取GitHub仓库的文件的一个东东啦~**

## 2. 怎么使用`git`？

### 2.1 把仓库拉取到本地

```git
git clone <你这个仓库的地址>
```

就是这么简单

### 2.2 写点东西

这是你在本地要干的事

### 2.3 第一次怎么把仓库推回去

先这样

```git
git add .
```

接着

```git
git commit -m "<你这一次干了啥（随你写）>"
```

然后

```git
git push -u origin main
```



### 2.4 以后怎么做

先这样

```git
git add .
```

接着

```git
git commit -m "<你这一次干了啥（随你写）>"
```

然后

```git
git push
```

几乎不变。。。

### 2.5 后话

所以，你应该会用git了
